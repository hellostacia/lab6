# Лабораторная работа №6. Отзывы к онлайн-курсам

Что добавлено:
- модель `Review` с оценкой, текстом, датой, связью с курсом и пользователем;
- отображение 5 последних отзывов на странице курса;
- страница всех отзывов `/courses/<course_id>/reviews`;
- пагинация отзывов;
- сортировка: по новизне, сначала положительные, сначала отрицательные;
- форма создания отзыва на странице курса и на странице всех отзывов;
- запрет на повторный отзыв от одного пользователя;
- пересчёт `rating_sum` и `rating_num` курса после добавления отзыва.

Демо-пользователь:
- логин: `user`
- пароль: `qwerty`
